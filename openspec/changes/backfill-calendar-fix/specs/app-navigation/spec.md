## MODIFIED Requirements

### Requirement: 日历多色渐变标记
当同一天有多个习惯的打卡记录时，日期格子 MUST 使用环形渐变（`radial-gradient`）展示多色标记，不得使用线性渐变。

#### Scenario: 多色环形渐变
- **WHEN** 某日期有 2 个及以上不同习惯的打卡记录
- **THEN** 该日期格子背景为 `radial-gradient(circle, ...)` 环形渐变，各习惯颜色从中心向外扩散

#### Scenario: 单色标记不变
- **WHEN** 某日期仅有一个习惯的打卡记录
- **THEN** 该日期格子使用该习惯颜色的半透明填充（与当前行为一致）

### Requirement: 日历选中日期高亮
用户选中的日期 MUST 始终有明显的视觉高亮，无论该日期是否有打卡标记。

#### Scenario: 无标记日期选中
- **WHEN** 用户选中一个没有打卡记录的日期
- **THEN** 该日期格子显示粉色边框和半透明粉色背景

#### Scenario: 有标记日期选中
- **WHEN** 用户选中一个有打卡标记（单色或多色）的日期
- **THEN** 该日期格子在保持标记颜色的基础上，叠加明显的选中高亮效果（如加粗边框 + 内阴影），与未选中的标记日期形成清晰对比

#### Scenario: 选中态与今日态区分
- **WHEN** 用户选中的日期恰好是今天
- **THEN** 选中态的高亮效果优先于今日态的边框样式
