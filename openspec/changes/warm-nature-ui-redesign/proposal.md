## Why

当前应用采用"多巴胺 + 玻璃拟态"配色方案（高饱和粉色 `#FF6B9D`、半透明毛玻璃背景、渐变页面底色），虽然活泼但整体质感偏冷、偏薄，与应用中"种树 🌳"、"钓鱼 🐟"、"收获 🌾"等自然生长隐喻存在视觉冲突。用户反馈整体 UI 表现不够满意，希望换成**暖色治愈系**风格——以大地色、自然插画色为基调，追求温暖、柔软、有呼吸感的视觉体验。

参考灵感来源为一套旅行/自然主题的 UI 配色方案，色板为：`#F98C53`（暖橙）、`#D2E0AA`（浅绿）、`#ABD7FB`（天空蓝）、`#F9F2EF`（奶油白）、`#FCCEB4`（蜜桃粉），搭配超大圆角卡片、色彩化柔和阴影、无边界设计。

## What Changes

- **全局色彩系统重构**：废除现有多巴胺色系（`--dopamine-pink` 等 8 个变量）和玻璃拟态变量（`--glass-blur`、`--glass-border`），替换为暖色治愈系调色板（5 个主色 + 语义色）。
- **全局背景色升级**：从冷白渐变 `linear-gradient(160deg, #FFF5F7, #F8F0FF, #F0F7FF)` 切换至纯暖白底色 `#F9F2EF`。
- **卡片质感重塑**：移除 `backdrop-filter: blur()` 毛玻璃效果，改为纯白实底 + 超大圆角（24px → 28px/32px）+ 色彩化弥散阴影（同色系低透明度阴影替代黑灰阴影）。
- **按钮系统更新**：主按钮从粉色渐变改为暖橙 `#F98C53` 实底 + 暖橙弥散阴影；辅助按钮使用蜜桃粉/浅绿。
- **底部导航栏改版**：从毛玻璃半透明改为实底暖白悬浮栏，激活态使用暖橙色。
- **排版与留白优化**：增大卡片内边距、行间距，提升整体呼吸感。
- **选中态 / 滚动条 / 细节色**：所有基于粉色 `rgba(255, 107, 157, ...)` 的交互反馈色替换为暖橙系。

## Capabilities

### New Capabilities
- `warm-nature-theme`: 暖色治愈系设计令牌（Design Tokens）与全局样式规范，定义色板、圆角、阴影、排版等视觉基础变量。

### Modified Capabilities
（无现有 spec 层面的行为变更，本次为纯视觉改版，不涉及功能逻辑变动）

## Impact

- **受影响文件**：`src/index.css`（全局变量）、`src/App.css`（全部组件样式）、各组件内联样式引用。
- **组件范围**：BottomNav、HabitTile、HabitForm、Calendar、CheckinModal、Timeline、PineTreeChart、FishingCatch、HabitOverviewList 等所有 UI 组件。
- **无功能性影响**：不涉及 JS 逻辑、路由、数据持久化、PWA 或 Garfish 生命周期的变更。
- **无依赖变更**：不新增或移除 npm 包。
- **兼容性**：移除 `backdrop-filter` 后，不再需要 `@supports not` 降级规则，低端浏览器兼容性反而提升。
