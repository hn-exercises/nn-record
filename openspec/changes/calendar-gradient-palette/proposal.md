# 提案：日历渐变改为调色盘自然过渡

## 问题定义

时光补页面中，多习惯日期的日历格子使用 `linear-gradient` 硬分段渐变（颜色之间无过渡，呈现锐利条纹），视觉效果生硬，不符合手帐风的柔和治愈美感。

## 目标

- 将多色日历格子的渐变从线性硬分段改为调色盘式自然过渡渐变。
- 保持单色日期不变（纯色背景）。

## 非目标

- 不改变日历整体布局或尺寸。
- 不改变颜色选择逻辑或数据结构。

## 方案对比

| 方案 | 效果 | 优点 | 缺点 |
|------|------|------|------|
| A: linear-gradient 无硬停（smooth） | 斜向自然过渡 | 简单、兼容好 | 方向单一，不够"调色盘" |
| B: conic-gradient（推荐） | 环形调色盘过渡 | 最像调色盘、色彩均匀环绕 | 需首尾衔接 |
| C: radial-gradient | 中心向外扩散 | 柔和 | 外圈颜色被截断 |

## 推荐方案

**方案 B: conic-gradient** — 使用 `conic-gradient(from 135deg, c1, c2, ..., c1)` 创建环形自然过渡，首尾闭合形成调色盘效果。

## 影响范围

- `src/components/Calendar.jsx` — `getMarkStyle` 函数
- 无其他模块受影响
