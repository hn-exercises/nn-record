## Why

当前三个页签（今日记 / 时光补 / 收获集）已具备基本功能，但交互与视觉体验存在可提升空间：

1. **今日记**：习惯色块上直接暴露打卡按钮和计数信息，导致卡片信息过密；点击色块跳转详情页与打卡行为耦合，缺乏打卡专属仪式感。
2. **时光补**：日历多色标记使用 radial-gradient 硬色带，视觉割裂；选中日期高亮容易被习惯色覆盖，辨识度不足。
3. **收获集**：只有图表视图，缺少按习惯维度的概览与钻取能力；热力图作为首屏图表缺少趣味性；渔获为浮动卡片交互，占用固定定位空间且 3 秒自动关闭体验仓促。

本次变更旨在优化三大页签的交互层次、视觉质感与信息架构。

## What Changes

### 今日记
- 习惯色块**仅展示名称 + 寄语**，右下方增加「前去打卡」文案提示
- **移除**色块上的打卡按钮、累计次数、今日次数
- 点击色块**唤起打卡弹窗**（而非跳转详情），弹窗底色为习惯颜色，展示名称/寄语/状态，支持**可选文案输入**，打卡后触发 confetti
- 色块增加卡片阴影与层次感样式优化
- 原色块点击跳转详情的功能**迁移至收获集概览**

### 时光补
- 日历多色渐变改为**柔和自然过渡**（类似调色盘色块），使用 CSS color-mix 或 linear-gradient 平滑混合
- 选中日期增加**独立高亮样式**（如缩放 + 阴影环），不再与习惯色冲突

### 收获集
- 页面右上角增加 **概览 / 图表** 切换
- **概览模式**：按习惯展示卡片（名称、寄语、累计打卡、今日状态），点击卡片进入习惯详情（名称、寄语、完整打卡时间线含日期与文案）
- **图表模式**：
  - 第一张图改为**松树时间轴**（横向滚动 SVG，灰色长方形树干 + 各习惯颜色三角形叠加为树冠）
  - 第二张图改为**内嵌渔获区域**（大长条色块，点击在区域内显示文案，再次点击刷新内容）
  - 第三张图起保持现有趋势折线图和甜甜圈

### 数据模型
- checkinStorage 扩展支持**打卡文案**（可选），每条打卡记录可附带文本备注

## Capabilities

### New Capabilities
- `checkin-modal`：打卡弹窗组件，以习惯颜色为底色，展示习惯信息，支持可选文案输入后打卡
- `checkin-notes`：打卡数据模型扩展，支持每条打卡记录附带可选文本备注
- `habit-overview`：收获集概览模式，按习惯卡片展示摘要信息，支持点击钻取到习惯详情页
- `pine-tree-chart`：松树时间轴 SVG 图表，横向滚动，按天展示各习惯打卡的叠加三角形树冠
- `inline-fishing-catch`：内嵌渔获区域组件，替代原浮动卡片，点击在区域内展示/刷新文案

### Modified Capabilities
- `todo-list-app`：日历渐变标记方式变更（硬色带 → 柔和混合）、选中日期高亮样式增强；今日记色块样式与交互行为变更（移除直接打卡、增加弹窗入口）
