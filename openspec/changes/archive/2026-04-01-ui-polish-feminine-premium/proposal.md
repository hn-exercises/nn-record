## Why

当前应用的视觉表现偏向 MVP / Demo 阶段：布局功能完备但缺乏设计感与情感温度。目标用户为 25-30 岁女性，她们对视觉品质、可爱细节与高级感有明确期待。需要一次系统性的 UI 抛光，让应用从"能用"跃升到"想用"，传递出"有专业 UI 设计师参与"的品质感。

## What Changes

- **色彩体系升级**：在现有多巴胺色基础上引入柔和渐变背景、玻璃拟态（glassmorphism）卡片、更精致的阴影层次；新增浅色渐变页面底色取代纯白，让视觉更温暖。
- **字体与排版精调**：引入 Google Fonts 中适合女性向的圆润字体（中文使用系统默认圆体，英文/数字引入 Nunito 或 Quicksand）；调整行高、字重、间距系统使层次更清晰。
- **底部导航重设计**：用自定义 SVG 图标替代纯 emoji，active 态增加微动效指示器（小圆点/下划线过渡），整体更精致。
- **习惯卡片视觉增强**：加入轻微的彩色渐变背景、精致的内阴影高光层、hover/active 微弹动效；新增卡片增加虚线呼吸动效。
- **打卡弹窗（CheckinModal）升级**：圆角更大、使用渐变色标题栏替代实色色条；textarea 增加柔和焦点光晕；按钮 hover 渐变过渡。
- **日历网格美化**：选中日期改用柔和渐变光晕（不仅缩放+描边）；今日标记加入脉冲微动效；标记日期改用带透明度的彩色圆点底色。
- **页面标题区域重设计**：h1 搭配装饰性 emoji 或轻量 SVG 插画；增加柔和渐变分割线或底纹装饰。
- **空状态与引导插画**：为"暂无习惯""暂无打卡记录"等空状态添加轻量可爱 SVG 插画或 emoji 组合构图，替代纯文字。
- **微交互与动效体系**：统一 transition timing-function 为弹性曲线；列表项入场增加 stagger 动画；打卡成功增加涟漪反馈；切换 tab 添加内容淡入。
- **收获集图表视觉升级**：松树图添加圆角与阴影、趋势线增加面积填充渐变、甜甜圈添加内圈装饰；渔获区域加入更可爱的插画元素。
- **表单与输入控件升级**：输入框加入柔和过渡内阴影；色彩选择器增加选中动效；按钮增加渐变背景与微光效果。
- **全局细节打磨**：自定义滚动条样式（细且柔和）；分割线/边框改用极细渐变线；增加 ::selection 选中文本色彩。

## Capabilities

### New Capabilities
- `visual-theme-system`：全局色彩/渐变/阴影/玻璃拟态设计体系（CSS 变量与 mixin）
- `typography-system`：字体引入、排版节奏、字重/间距统一规范
- `micro-interaction`：过渡动效、入场动画、弹性曲线、反馈动效体系
- `empty-state-illustration`：空状态 SVG 插画/emoji 艺术组合
- `bottom-nav-redesign`：底部导航自定义图标与 active 态动效指示器
- `component-visual-polish`：各组件（卡片/弹窗/日历/表单/图表）视觉细节升级

### Modified Capabilities
_无现有规范层级的行为变更，所有改动均为视觉/样式层面，不修改功能逻辑。_

## Impact

- **文件影响**：`src/index.css`（变量体系）、`src/App.css`（~1300 行全面修订）、所有组件 JSX 文件（className 微调、结构补充装饰元素）、`index.html`（字体 CDN 引入）
- **依赖变更**：无新 npm 依赖；通过 Google Fonts CDN 引入 1-2 款 Web 字体
- **兼容性**：所有变更为纯 CSS + 轻量 JSX 结构调整，不影响数据层（checkinStorage/habitStorage）、路由、PWA 配置
- **风险**：CSS 改动范围大，需逐组件对照验收；部分 glassmorphism 效果在低端安卓 WebView 中可能降级（需设置 fallback）
