## Why

当前习惯打卡应用的交互和视觉设计偏向开发者风格（深色系、列表布局），不符合目标用户群体（25-30岁年轻女性）的审美偏好。同时，习惯管理功能不完善（只能新增不能删改），底部导航包含了尚未使用的"待办计划"和"Todo"入口造成困惑，打卡体验缺乏正向反馈的仪式感。需要从交互和 UI 两个维度进行全面重设计，打造简洁、可爱、多巴胺色系的轻松体验。

## What Changes

**交互改动：**
- **BREAKING** 移除底部导航的"待办计划"和"Todo"两个 Tab，仅保留"习惯打卡"Tab（底部 Tab 栏保留，供未来扩展）
- 习惯页布局从纵向列表改为 2 列方块网格，每个习惯占一个大方块
- 新增习惯的交互改为网格末尾的"+"方块卡片，不再使用底部全宽按钮
- 习惯支持删除和编辑（名称、寄语、开始时间、颜色）
- 点击习惯方块进入详情页，以时间轴形式展示该习惯的打卡记录
- 打卡成功时触发全屏撒花动效，增强正向反馈仪式感

**UI 改动：**
- 整体配色从深色系切换为白色基底 + 多巴胺彩色模块
- 采用多巴胺色系（明亮粉、薄荷绿、柠檬黄、薰衣草紫、珊瑚橙等），色彩搭配活泼但和谐
- 风格简洁、可爱，面向 25-30 岁年轻女性用户群体
- 预设颜色板更新为多巴胺色系

## Capabilities

### New Capabilities
- `confetti-effect`: 打卡成功时的全屏撒花/彩带动效组件
- `habit-timeline`: 习惯详情页，以时间轴形式展示打卡历史记录
- `dopamine-theme`: 白色基底 + 多巴胺色系的全局 UI 主题重设计

### Modified Capabilities
- `habit-tracking`: 习惯支持删除与编辑；布局从列表改为 2 列方块网格；新增习惯改为"+"方块卡片交互
- `app-navigation`: 移除待办计划和 Todo 的底部 Tab，仅保留习惯打卡（Tab 栏保留供扩展）

## Impact

- **前端组件**：HabitHome、HabitForm、BottomNav 需要大幅重构；新增 HabitDetail（时间轴）、Confetti 组件
- **路由**：移除 /planner、/planner/done、/todo 路由，新增 /habit/:id（习惯详情）
- **数据层**：habitStorage.js 需新增 updateHabit 方法
- **样式**：index.css 和 App.css 全面重写，从暗色切换为白色多巴胺主题
- **预设颜色**：HabitForm 中的 PRESET_COLORS 更新为多巴胺色系
- **依赖**：可能新增轻量 canvas-confetti 库或自行实现 CSS/Canvas 撒花动效
