## ADDED Requirements

### Requirement: 白色基底全局背景
应用 MUST 使用白色（#FFFFFF）作为主背景色，替代当前的深色背景。

#### Scenario: 页面背景
- **WHEN** 用户打开应用的任何页面
- **THEN** 页面背景为白色，文字主色为深色（#2D2D2D）

### Requirement: 多巴胺色系设计 Token
应用 MUST 定义多巴胺色系 CSS 变量作为全局设计 Token，包含明亮粉、薄荷绿、柠檬黄、薰衣草紫、珊瑚橙、天空蓝、蜜桃色、丁香紫。

#### Scenario: 色彩 Token 可用
- **WHEN** 任何组件需要使用主题色
- **THEN** 可通过 CSS 变量引用多巴胺色系颜色

### Requirement: 习惯预设颜色更新
习惯创建/编辑表单中的预设颜色 MUST 更新为多巴胺色系。

#### Scenario: 创建习惯选择颜色
- **WHEN** 用户在新增习惯表单中选择颜色
- **THEN** 颜色选项为多巴胺色系（明亮粉、薄荷绿、柠檬黄、薰衣草紫、珊瑚橙、天空蓝、蜜桃色、丁香紫）

### Requirement: 模块化彩色卡片
习惯卡片 MUST 使用用户选择的多巴胺色作为卡片背景色（浅色调），文字颜色自适应确保可读性。

#### Scenario: 卡片彩色背景
- **WHEN** 用户查看习惯首页的方块网格
- **THEN** 每个习惯方块使用该习惯自选颜色的浅色调作为背景，文字为深色以保证对比度

### Requirement: 简洁可爱的视觉风格
整体 UI MUST 呈现简洁、可爱的视觉风格，适合 25-30 岁年轻女性用户群体。

#### Scenario: 圆角与间距
- **WHEN** 用户查看应用界面
- **THEN** 卡片和按钮使用较大的圆角（16-20px），间距舒适，无视觉拥挤感

#### Scenario: 底部导航样式
- **WHEN** 用户查看底部导航栏
- **THEN** 导航栏为白色背景，选中项使用多巴胺色高亮，整体简洁不厚重
