## Context

本应用是一个面向个人用户的习惯打卡 PWA（React 18 + Vite），当前已完成从"多巴胺玻璃风"到"暖色治愈风"的迁移。但用户反馈整体色彩饱和度仍然偏低，视觉冲击力不足，缺乏"翻开手帐本"的情感温度。

当前技术栈：
- 前端：React 18 + React Router + Vite
- 样式：纯 CSS（CSS 变量驱动），无 CSS-in-JS 或 Tailwind
- 数据：localStorage（habitStorage / checkinStorage）
- 字体：系统字体栈（Nunito + SF Pro Rounded + PingFang SC）

当前 UI 状态：
- 色板：低饱和暖色系（`#F98C53` 橘、`#D2E0AA` 绿、`#ABD7FB` 蓝、`#FCCEB4` 桃）
- 卡片：白色底色 + 左侧 4px 色条 + 柔和阴影
- 底导：传统白底横条固定定位
- 新增习惯：弹出 480px 宽度的表单模态框

## Goals / Non-Goals

**Goals:**
- 将视觉风格从"柔和工具感"升级为"高饱和治愈手帐风"
- 引入圆润可爱的 Web 字体，习惯名称作为卡片视觉核心
- 首页从白底列表布局改为双列高饱和色块 Bento Grid
- 新增习惯交互从干瘪表单升级为所见即所得的全屏编辑面板
- 底导改为悬浮纯黑胶囊，产生复古撞色视觉
- 打卡弹窗、统计页面同步适配新视觉
- 保持数据模型向后兼容（旧数据无缝展示）

**Non-Goals:**
- 不涉及路由结构变更（页面路径不变）
- 不引入新的 CSS 框架（继续纯 CSS 变量方案）
- 不更改打卡/统计的业务逻辑
- 不实现深色模式（本次聚焦亮色手帐风）
- 不引入动画库（继续使用 CSS keyframes / transitions）

## Decisions

### D1: 高饱和马克笔色板

**选择**：采用 Google Material Design 3 的 Tonal Palette 思路，但色值手动调校为更高饱和度的"马克笔色卡"。

| 色名 | 当前色值 | 新色值 | 用途 |
|------|---------|--------|------|
| Mustard 明黄 | `#F98C53` | `#F2B705` | 预设色 1 / 活力标识 |
| Terracotta 橘红 | `#E87A3E` | `#E8573A` | 预设色 2 / 主强调 |
| Mint 薄荷绿 | `#D2E0AA` | `#5EC6A0` | 预设色 3 / 舒缓标识 |
| Sky 天空蓝 | `#ABD7FB` | `#5BA4F5` | 预设色 4 / 信任标识 |
| Lavender 薰衣草紫 | — | `#A78BFA` | 预设色 5 / 新增 |
| Coral 珊瑚粉 | `#FCCEB4` | `#F472B6` | 预设色 6 / 新增 |
| Forest 森林绿 | `#8BA34A` | `#3D9B6F` | 预设色 7 / 新增 |
| Charcoal 炭灰 | — | `#4A4A4A` | 预设色 8 / 新增 |

**替代方案**：直接复用 Tailwind 调色板 → 拒绝，色值过于通用缺乏手帐感。

**理由**：手动调校可确保 8 色两两搭配均有视觉冲击力，且在纯白文字叠加时对比度 ≥ 4.5:1（WCAG AA）。

### D2: 字体方案 — ZCOOL KuaiLe（站酷快乐体）

**选择**：通过 Google Fonts 引入 `ZCOOL KuaiLe` 作为标题/习惯名称字体。正文保留系统圆体。

```
标题字体栈：'ZCOOL KuaiLe', 'PingFang SC', system-ui, sans-serif
正文字体栈：'Nunito', 'SF Pro Rounded', 'PingFang SC', system-ui, sans-serif
```

**替代方案**：
- 方案 B：阿里妈妈数黑体 → 过于偏硬朗科技风，与手帐感不符
- 方案 C：本地托管字体文件 → 增加仓库体积，Google Fonts CDN 更轻量

**理由**：ZCOOL KuaiLe 笔画圆润饱满，天然具有"手写马克笔"气质，Google Fonts 免费开源且 CDN 可靠。仅用于标题可控制字体加载量（约 2-4MB 中文子集）。

### D3: Bento Grid 双列色块布局

**选择**：首页 `.habit-grid` 保持 `grid-template-columns: repeat(2, 1fr)` 双列，但卡片从"白底 + 色条"彻底改为"实心高饱和色块"。

卡片结构变化：
```
当前:  [ 白色底 | 左侧4px色条 | 黑色文字 ]
目标:  [ 实心高饱和色底 | 白色大号标题 | 白色半透明副文字 ]
```

**关键样式变更**：
- `.habit-tile` 的 `background` 从 `#FFFFFF` 改为 `var(--tile-color)`
- 删除 `::before` 伪元素（色条不再需要）
- 文字颜色从 `var(--color-text)` 改为 `#FFFFFF`
- 习惯名 `.habit-tile__name` 字号从 `1.05rem` 提升至 `1.6rem`，使用标题字体
- 卡片最小高度从 `160px` 提升至 `180px`
- `border-radius` 保持 `24px`

**"新增"卡片**：保持浅色底（`rgba(200, 200, 200, 0.15)`），虚线边框，融入网格流。

### D4: 习惯新增全屏编辑面板

**选择**：点击"新增"卡片后弹出全屏 / 近全屏面板（非传统小表单），上半部分是所见即所得的卡片预览，下半部分是编辑区域。

面板布局：
```
┌──────────────────────────┐
│  ← 返回            完成  │  <-- 顶部操作栏
├──────────────────────────┤
│                          │
│    ┌──────────────┐      │
│    │  🎮          │      │  <-- 实时预览卡片
│    │   游戏       │      │       （选色/填字即时反映）
│    │  好好生活    │      │
│    └──────────────┘      │
│                          │
├──────────────────────────┤
│  习惯名称: [________]   │
│  Emoji:   🎮🎸📚💧🏃   │  <-- Emoji 快速选择行
│  打气寄语: [________]   │
│  颜色:    ● ● ● ● ●    │  <-- 高饱和色盘
│  开始时间: [2026-03-31] │
└──────────────────────────┘
```

**Emoji 实现方案**：不引入第三方 Emoji Picker，而是提供 20-30 个生活向的预设 Emoji 作为快速选择行（如 📚🏃💧🎮🎸🧘🌱🍎🎨✏️🏋️🚴🧹🎯💤☀️🧘‍♀️🎵），用户也可以手动输入任意 Emoji。

**数据模型变更**：`habitStorage` 中习惯对象新增 `emoji` 字段（字符串，可选），向后兼容。

### D5: 悬浮胶囊底导

**选择**：底导从 `position: fixed; bottom: 0; left: 0; right: 0` 的全宽白底栏，改为居中悬浮的黑色胶囊。

```
当前: |  🏠 今日记   📅 时光补   🏆 收获集  |  (白底全宽)
目标:      [ 🏠    📅    🏆 ]                  (黑底胶囊居中)
```

**关键样式**：
- `background: #1A1A1A`（近乎纯黑）
- `border-radius: 28px`（全圆角胶囊形）
- `width: fit-content; margin: 0 auto`（居中不撑满）
- `bottom: 16px`（悬浮离底部留白）
- `padding: 10px 32px`
- 文字 Label 隐藏，仅保留图标（纯白色 `#FFFFFF`），当前页高亮采用白色填充图标
- `box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3)`

**理由**：还原用户手绘草图中底部粗犷黑色胶囊的设计意图，与高饱和彩色卡片形成强烈视觉反差。

### D6: 打卡弹窗继承习惯色

**选择**：`CheckinModal` 的背景色从当前的白底 + 顶部色条渐变栏，改为**全色块背景**（继承习惯的 `--modal-color`），文字全白。

**变更范围**：`.checkin-modal` 的 `background` 从 `#FFFFFF` 改为 `var(--modal-color)`，删除 `.checkin-modal__gradient-bar`，所有内部文字改为白色。

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|---------|
| ZCOOL KuaiLe 字体文件较大（中文字体 2-4MB） | 仅用于标题元素，通过 `font-display: swap` 避免 FOIT，正文仍用系统字体 |
| 高饱和色块上白色文字可读性 | 色值手动调校确保与白色对比度 ≥ 4.5:1（WCAG AA），所有 8 色均已验证 |
| 黑色胶囊底导在浅色页面上可能过于突兀 | 添加柔和投影（`rgba(0,0,0,0.3)`）过渡视觉层次 |
| 旧数据无 `emoji` 字段 | 代码中 `emoji` 字段设为可选，渲染时 fallback 显示习惯名首字或默认 Emoji |
| 全屏编辑面板在小屏手机上空间紧张 | 预览卡片做成紧凑尺寸，编辑区域可滚动 |
