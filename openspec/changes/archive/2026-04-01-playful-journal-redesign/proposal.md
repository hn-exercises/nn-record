## Why

当前应用虽然完成了从"多巴胺玻璃风"到"暖色治愈风"的过渡，但整体视觉仍然偏"浅"、缺乏冲击力。现有的柔和色系（`#F98C53` 等低饱和度暖色）在用户感知上不够"活泼"。同时，首页的列表式布局和传统的表单新增流程缺乏情感温度，更接近"工具"而非"手帐日记"。

用户希望将整个应用转型为**治愈手帐风（Playful Journal）**——高饱和度马克笔色块 + 圆润可爱字体 + Bento Grid 布局 + 悬浮胶囊底导，使其在视觉和交互上像翻开一本属于自己的手绘日记本。

## What Changes

- **色彩系统重构**：从当前低饱和暖色系升级为高饱和"马克笔色板"（明黄、橘红、薄荷绿、天空蓝等），卡片直接以高纯度实心色块为底色
- **字体系统引入**：全局引入圆润可爱的 Web 字体（如 ZCOOL KuaiLe / 站酷快乐体），习惯名称采用大字号设计感排版，作为卡片视觉中心
- **首页布局重构**：从列表式习惯卡片改为双列色块 Bento Grid 网格，"新增"入口融入网格成为最后一个浅色卡片
- **新增习惯交互重构**：弹出全屏编辑面板，支持完全自定义（名称、寄语、Emoji 图标、高饱和色盘选色），编辑过程即所见即所得的卡片预览
- **悬浮胶囊底导**：底部导航从传统白底横条改为居中悬浮的纯黑胶囊形态（黑底 + 白色图标），强烈复古撞色
- **打卡弹窗同步改造**：弹窗继承习惯专属高饱和色块为底色，配合大号圆体字
- **统计页面手帐风改造**：图表线条变粗、数据展示从商务风转向手绘日记风格

## Capabilities

### New Capabilities
- `playful-theme-system`：高饱和马克笔色板系统与圆润可爱字体全局方案，包含 CSS 变量重构与 Web 字体引入规范
- `bento-grid-layout`：首页双列色块网格布局规范，包含习惯卡片沉浸式色块展示与"新增"卡片融入网格的交互
- `habit-form-redesign`：习惯新增/编辑的全屏面板交互规范，包含所见即所得卡片预览、Emoji 选择、高饱和色盘选色
- `floating-pill-nav`：悬浮胶囊形底部导航的视觉与交互规范

### Modified Capabilities
- （无现有规范需要修改——当前 `openspec/specs/` 中仅有 `todo-list-app`，与本次改动无关）

## Impact

- **CSS 全局变量**：`src/index.css` 的 `:root` 色板需全面替换为高饱和色值，字体栈需追加 Web 字体
- **组件样式**：`src/App.css` 中 `.habit-tile`、`.bottom-nav`、`.checkin-modal`、`.habit-form` 等核心选择器需重写
- **React 组件**：
  - `HabitHome.jsx`：布局结构从列表改为 Bento Grid
  - `HabitForm.jsx`：从简单表单升级为全屏所见即所得编辑面板，新增 Emoji 选择器
  - `CheckinModal.jsx`：背景色方案改为高饱和色块
  - `BottomNav.jsx`：结构改为悬浮胶囊
  - `HarvestHome.jsx`、`PineTreeChart.jsx`：图表风格同步改造
- **外部依赖**：需引入 Web 字体资源（Google Fonts 或本地托管）
- **数据模型**：习惯数据需新增 `emoji` 字段（`habitStorage.js`），向后兼容现有数据
