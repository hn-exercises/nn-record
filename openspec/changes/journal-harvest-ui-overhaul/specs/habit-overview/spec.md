## ADDED Requirements

### Requirement: 概览/图表模式切换
收获集页面 MUST 在页面右上角提供概览与图表两种模式的切换按钮。

#### Scenario: 默认显示概览模式
- **WHEN** 用户进入收获集页面
- **THEN** 默认展示概览模式，概览按钮处于激活状态

#### Scenario: 切换到图表模式
- **WHEN** 用户点击"图表"按钮
- **THEN** 页面内容切换为图表视图，图表按钮处于激活状态

#### Scenario: 切换回概览模式
- **WHEN** 用户在图表模式下点击"概览"按钮
- **THEN** 页面内容切换为概览视图

### Requirement: 概览模式习惯卡片列表
概览模式 MUST 按习惯展示卡片列表，每张卡片显示习惯摘要信息。

#### Scenario: 卡片展示习惯摘要
- **WHEN** 概览模式加载
- **THEN** 每张卡片显示习惯名称、寄语、累计打卡次数、今日是否已打卡标记（✅ 或 ⬜）

#### Scenario: 无习惯时显示空状态
- **WHEN** 用户未创建任何习惯
- **THEN** 概览模式显示"暂无习惯"空状态提示

### Requirement: 卡片点击展开详情
用户点击概览卡片 MUST 展开该习惯的详情面板，展示完整打卡记录。

#### Scenario: 展开习惯详情
- **WHEN** 用户点击某张习惯卡片
- **THEN** 卡片下方展开详情面板，显示习惯名称、寄语、完整打卡时间线（含日期和文案）

#### Scenario: 再次点击收起详情
- **WHEN** 用户点击已展开的卡片
- **THEN** 详情面板收起

#### Scenario: 同时只展开一个
- **WHEN** 用户在卡片 A 已展开时点击卡片 B
- **THEN** 卡片 A 收起，卡片 B 展开

### Requirement: 详情面板展示打卡时间线
展开的详情面板 MUST 复用 Timeline 组件展示该习惯的完整打卡记录。

#### Scenario: 展示打卡时间线含文案
- **WHEN** 详情面板展开
- **THEN** 时间线按日期分组展示所有打卡记录，有文案的记录显示文案内容

### Requirement: 详情面板支持编辑和删除
展开的详情面板 MUST 提供编辑和删除习惯的操作入口。

#### Scenario: 编辑习惯
- **WHEN** 用户在详情面板点击编辑按钮
- **THEN** 弹出习惯编辑表单（复用 HabitForm）

#### Scenario: 删除习惯
- **WHEN** 用户在详情面板点击删除按钮并确认
- **THEN** 习惯及其所有打卡记录被删除，卡片从列表中移除
