## ADDED Requirements

### Requirement: 收获集统计页面入口
收获集页面 MUST 作为底部「收获集」Tab 对应的页面，展示基于打卡记录的可视化统计图表。

#### Scenario: 进入收获集页面
- **WHEN** 用户点击底部「收获集」Tab
- **THEN** 路由跳转到 /harvest，展示统计图表页面

### Requirement: 打卡热力图
收获集页面 MUST 展示一个类 GitHub contribution 风格的全年热力图，按天聚合所有习惯的打卡次数，映射为颜色深浅。

#### Scenario: 热力图展示
- **WHEN** 用户查看收获集页面
- **THEN** 页面顶部展示当前年份的热力图，每个日期格子根据该天总打卡次数显示不同深浅的颜色（0次为空白，次数越多颜色越深）

#### Scenario: 热力图无数据
- **WHEN** 当前年份没有任何打卡记录
- **THEN** 热力图所有格子为空白色，下方显示提示文字

### Requirement: 趋势折线图
收获集页面 MUST 展示最近 30 天每天的打卡次数趋势折线图。

#### Scenario: 折线图展示
- **WHEN** 用户查看收获集页面
- **THEN** 页面展示一个折线图，X 轴为最近 30 天的日期，Y 轴为当天总打卡次数

#### Scenario: 折线图数据不足 30 天
- **WHEN** 用户的打卡历史不足 30 天
- **THEN** 折线图仅展示有数据的日期范围，空缺日期显示为 0

### Requirement: 习惯占比环形图
收获集页面 MUST 展示各习惯打卡次数占比的环形图（甜甜圈图），使用各习惯对应的多巴胺色。

#### Scenario: 环形图展示
- **WHEN** 用户查看收获集页面，且存在多个习惯
- **THEN** 页面展示环形图，每段弧形代表一个习惯，颜色为该习惯的自选色，中心显示总打卡次数

#### Scenario: 仅有一个习惯
- **WHEN** 用户只有一个习惯
- **THEN** 环形图显示为该习惯颜色的完整圆环

### Requirement: 图表基于纯 SVG 实现
所有图表 MUST 使用纯 SVG 元素实现，不依赖第三方图表库。

#### Scenario: 无额外图表依赖
- **WHEN** 项目构建时
- **THEN** 不包含 chart.js、recharts、echarts 等图表库的依赖
